# Research and Sources

Agent Memory uses research to **learn, challenge, and bound** the architecture. Citations are not decorative authority, and public availability is not permission to copy someone else's work.

## Evidence posture

For consequential claims, the project tries to preserve:

```text
supporting evidence
challenging evidence
boundary conditions
implementation evidence
conformance evidence
known uncertainty
```

A useful source may strengthen current doctrine, weaken it, reveal a missing boundary, or show that a favored analogy has been stretched too far.

## Cross-domain memory claims

When a concept moves from biological, cognitive, organizational, or other memory systems into agent engineering, classify the relationship:

| Class | Meaning |
|---|---|
| **MECHANISM** | Demonstrated in the original substrate. |
| **FUNCTIONAL ANALOGY** | A similar problem or role appears in another substrate. |
| **ENGINEERING PRESCRIPTION** | A software requirement justified independently by agent evidence, governance, or operational risk. |
| **OPEN HYPOTHESIS** | A design candidate still requiring validation. |

This prevents metaphor from quietly becoming mechanism.

## Preferred evidence

When quality is comparable, prefer sources that other readers can inspect:

- open-access journals
- PubMed Central and comparable public archives
- lawful preprints
- open conference proceedings
- standards and government publications
- public technical reports
- open datasets and benchmark repositories
- public implementation artifacts

Accessibility helps reproducibility. It does not replace source quality.

## Public source does not mean reusable source

Agent Memory distinguishes **citation** from **reuse**.

Default treatment:

| Situation | Default treatment |
|---|---|
| Public URL | Link as provenance |
| Facts, findings, ideas | Independently synthesize and cite |
| Distinctive prose | Do not reproduce by default |
| Short quotation needed for analysis | Attribute precisely and keep minimal |
| Diagram, figure, table, screenshot | Do not copy without verified permission/license |
| Source code | Reuse only under a compatible verified license and satisfy obligations |
| Unknown/no license | Citation-only or independent synthesis |

GitHub issue comments and discussions deserve special care: a repository's software license should not automatically be assumed to cover every third-party comment posted there.

## Native doctrine versus external evidence

PAMA is native Agent Memory doctrine authored by Kevin R. Knapp. It does not belong in the external source registry.

External repositories or research appear only where they provide actual evidence, comparison, implementation, or provenance value.

## Source-rights registry

Material external sources are tracked with machine-readable rights metadata so reuse-oriented entries cannot silently omit their reuse basis.

The registry records fields such as:

- source locator
- source type
- originator/owner
- access status
- license or rights status
- reuse mode
- attribution/notice obligations
- reused material
- reuse basis

## Contribute evidence

Use the repository's **Research or evidence submission** issue form. Strong contradictory evidence is welcome. An architecture that only collects sources agreeing with itself is not research; it is scrapbooking with footnotes.
