# Agent Memory operator skills

This directory contains reusable operator-facing skills that apply Agent Memory doctrine to bounded real-world evaluation and implementation work.

Skills are procedures, not standing authority. A skill may define how to gather evidence, structure an evaluation, or produce an implementation artifact. It does not grant permission to mutate canonical memory, repository governance, production systems, or external organizations.

Current skills:

- [`github-governance-memory-efficacy`](github-governance-memory-efficacy/SKILL.md) — establish a frozen GitHub repository or organization baseline, model evidence-based Agent Memory benefit targets, and prepare a matched post-implementation T3 evaluation.
