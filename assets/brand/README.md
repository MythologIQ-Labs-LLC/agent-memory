# Agent Memory brand assets

These assets are presentation surfaces for the **Agent Memory** repository. They do not define doctrine, conformance, lifecycle state, authority, or interoperability guarantees.

## Brand hierarchy

Agent Memory is a **MythologIQ Labs** repository first.

- **MythologIQ Labs** supplies the primary visual lineage: dark cosmic field, luminous cyan/blue, restrained gold, continuity, discovery, and a slightly mythic technical character.
- **Agent Governance Toolkit (AGT)** is an architectural and presentation influence only. Its influence should appear as clarity, disciplined geometry, and governance-conscious structure rather than copied branding or a shield-led identity.
- **AgenTrust** is future-facing connective tissue and interoperability ambition. Agent Memory branding must not imply current dependency, certification, endorsement, or completed AgenTrust integration.

## Logo semantics

The logo intentionally uses a database-like stack because Agent Memory is durable structured state, not a symbolic brain.

- **Stacked disks:** durable and layered memory state.
- **Connected nodes:** relationships, provenance, and structured memory connections. The three-node mark is illustrative, not a normative claim that Agent Memory has exactly three edge types.
- **Orbit:** continuity and memory evolution across time.
- **Cyan star / spark:** inference, discovery, or the active agent spark. Inference may propose; it does not manufacture authority.
- **Gold accent:** MythologIQ visual lineage and continuity. Gold does not mean truth, certification, authority, or permanence.

## Canonical presentation assets

- `agent-memory-mark.svg` — compact SVG emblem without text. Use for documentation indexes, avatars, small cards, and surfaces where the project name is already visible.
- `agent-memory-logo-lockup.svg` — square SVG logo with project name. Use for release cards, presentations, repository announcements, and other square placements.
- `agent-memory-readme-banner.webp` — wide GitHub README / social-preview-ready banner.
- `agent-memory-wiki-cover.webp` — more atmospheric cover for the Wiki Home page.

The compact mark and square lockup are intentionally SVG-native. Do not raster-convert them for repository use unless a destination explicitly requires a raster format. The README and Wiki hero assets remain raster because their atmospheric backgrounds benefit from that treatment.

## Usage guidance

Keep the visual system restrained. A logo on every page adds noise rather than professionalism.

Prefer:

1. the README banner on the repository landing page;
2. the Wiki cover on Wiki Home;
3. the compact mark on major documentation indexes or small identity surfaces;
4. the square lockup for external cards and announcements.

Do not use branding imagery as evidence for architectural claims. Nearby text and canonical numbered documentation remain authoritative.

### Accessibility

Every Markdown embed must include useful alt text. Do not rely on color to communicate architectural meaning, and do not place important doctrine exclusively inside artwork.
