# Failure Memory Type-Isolation Acceptance

This bounded acceptance surface belongs to #471.

A specialized failure-memory recall surface may narrow the adapter's governed admitted set, but it may never broaden it. An admitted fact that is not owned by the failure-memory lineage must be reported as a memory-type mismatch and must not become active failure guidance. A superseded failure revision must not become active, even if the substrate admits it for historical inspection. The current admissible failure revision may become active. Disputed and retracted failure state remains inactive. These filters have no mutation or action authority.
