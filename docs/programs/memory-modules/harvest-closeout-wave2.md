## UOR-R4 benchmark harvest result

The first #483 implementation run was valuable precisely because it did not merely confirm the test author's expectation.

The original benchmark assumed:

```text
superseded fact -> must never be a retrieval candidate
```

Exact execution disproved that assumption. Superseded fact identities can remain discoverable as historical candidate evidence while governed final admission refuses them as current context.

The benchmark was corrected to the actual architecture:

```text
candidate generation may surface historical evidence
  != current influence

superseded fact admitted as current context
  == currentness failure
```

Accordingly:

- stale candidate rate is diagnostic;
- stale admission rate is the currentness gate;
- matched controls remain load-bearing;
- unqualified correction and wrong-scope recall remain governance negatives;
- midpoint/final restart recovery remains required;
- quality, performance, governance, and recovery remain separate.

This is a harvested lesson improving Agent Memory without adopting UOR-R4's geometry or runtime.
