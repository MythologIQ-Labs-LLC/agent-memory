## Competitive maturity: #601

### Independent harness boundary

The external AMB harness is frozen at:

`vectorize-io/agent-memory-benchmark@03c1d0f1d27da63034f0931121c858faba512383`

Agent Memory is injected as an AMB `MemoryProvider` without modifying external benchmark source.

AMB remains responsible for:

- dataset loading;
- benchmark prompts;
- answer generation where applicable;
- judging/scoring;
- result formatting.

Agent Memory contributes only the `prepare -> ingest -> retrieve` bridge through the public `AgentMemory` facade.

The bridge preserves deterministic user isolation, maps source timestamps only to caller-declared `observed_at`, and records query timestamps without turning them into memory authority.

### Credential-free external retrieval lane

The frozen AMB `RetrievalMode` explicitly makes no LLM calls. Its PrecisionMemBench profile scores the returned belief/document IDs directly.

The merged manual workflow therefore admits:

```text
dataset: precisionmembench
split: single-turn
mode: retrieval
providers: agent-memory, bm25
```

without a real model credential. The external CLI still constructs an answer client before mode selection, so the workflow may provide an inert placeholder key only for this retrieval-only path. That placeholder is not used by the benchmark logic.

**No competitive score is accepted yet.** The manual workflow must still be deliberately dispatched and the raw evidence artifact reviewed before any result enters the canonical dashboard.

## Runtime maturity: #602

ADR-028 remains Accepted and controlling:

```text
normative doctrine
    !=

```

Python remains the qualified runtime/reference implementation today. Rust is being evaluated as a first-class implementation profile, not declared the replacement language.

### Merged deterministic shadow evidence

The Rust shadow crate is deliberately not linked into the runtime.

It currently reproduces:

- Agent Memory relevance tokenization;
- admitted-set BM25 using the #576 deterministic sorted-term accumulation order;
- UTF-8 SHA-256 digests.

Frozen cross-language fixtures are shared by Python and Rust.

Accepted qualification evidence:

- workflow run `36457677348`: exact token vectors and every BM25 IEEE-754 score bit reproduced on the Ubuntu CI profile, including the exact-tie case;
- workflow run `36458112635`: BM25 parity retained and SHA-256 vectors reproduced exactly.

This is meaningful evidence that selected deterministic primitives are portable. It is not yet evidence that Rust provides a better complete runtime.

### Next Rust sequence

```text
explicit canonical byte / serialization contract
  -> candidate index / search hot paths
  -> integrity / state primitives
  -> minimal open -> remember -> recall -> restart shadow
  -> matched Python/Rust performance + operational evidence
  -> explicit A/B/C/D runtime decision
```

Decision candidates:

```text
A. Python remains preferred
B. Python facade + Rust performance/assurance kernel
C. native Rust runtime + Python bindings
D. parallel conformant Python and Rust profiles
```

A hybrid Rust kernel remains preferable to a wholesale rewrite if it captures most measurable benefit with substantially less semantic and maintenance risk.
