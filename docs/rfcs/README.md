# Requests for Comment

RFCs define implementation-facing architecture proposals that are broader than one issue but are not themselves canonical doctrine.

Canonical doctrine belongs in ADRs and numbered architecture documents. RFCs may describe system shape, interfaces, sequencing, alternatives, and open implementation questions while those details are still being refined.

| RFC | Status | Purpose |
|---|---|---|
| [`RFC-001-governed-mutable-memory-fabric.md`](RFC-001-governed-mutable-memory-fabric.md) | Proposed | Define Agent Memory as a governed configurable memory fabric between Agent Runtime and peer Agent Governance systems, with heterogeneous memory technologies implemented as modules. |

An RFC does not grant an implementation conformance status or override an Accepted ADR.
