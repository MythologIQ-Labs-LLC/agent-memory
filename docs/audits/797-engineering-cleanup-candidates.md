## Priority 2: low-risk code hygiene (style only, behaviour-preserving)

### 2.1 Consolidate duplicate hashing/JSON helpers behind one `core` utility

- **Files (definitions):** `api/surface.py:206`, `contracts/cognitive_classification.py:40,44`, `contracts/hindsight_qualification.py:339`, `contracts/memos_qualification.py:353`, `contracts/resource_exchange.py:355`, `core/contextual_recall.py:25`, `core/portable_evidence.py:48`, `evaluation/identity_link_journal.py:70`, `evaluation/normalize.py:27`, `evaluation/temporal_currentness.py:336`, `evaluation/ui_catalog.py:29,33`, `harness/architecture_family_closeout.py:14`, `harness/architecture_family_evidence.py:19`, `harness/checkpoint_behavior_harness.py:41`, `memory/a2a_collaboration.py:45`, `memory/agent_manifest_external_evidence.py:68`, `memory/approval_evidence.py:27`, `memory/checkpoint_migration.py:182,186`, `memory/cmcp_external_evidence.py:80`, `memory/enforcement_evidence.py:28`, `memory/external_evidence.py:113`, `memory/framework_lifecycle.py:41`, `memory/mcp_interaction.py:47`, `memory/metabolism.py:64,68`, `memory/policy_projection_compatibility.py:38`, `memory/reusable_grants.py:32`, `memory/runtime_trace_correlation.py:39`, `memory/security_finding.py:71,81`, `memory/temporal_commitment.py:70`, `memory/temporal_transparency.py:26`, `runtime/configured_restart.py:96,111`, `runtime/restart_runtime.py:452,456`, `runtime/sqlite_runtime.py:67`, `state/sqlite_substrate.py:56` (all under `reference/agentmem_ref/`).
- **Why it is not harmless by default:** these helpers do not all compute the same bytes. Some serialise with `json.dumps(sort_keys=True, separators=(",", ":"))`, some with default separators, some via RFC 8785 JCS (`rfc8785`), and some hash a string rather than a document. Several outputs are **persisted identities**: generation journal digests (`restart_runtime`, `sqlite_runtime`, `sqlite_substrate`), evidence digests bound into frozen reports (`evaluation/normalize`, `temporal_currentness`, `identity_link_journal`), and receipt references. Changing any of their bytes changes evidence identity and breaks replay comparisons.
- **Safe shape:** (a) add `core/digests.py` exposing the two or three distinct canonical forms that actually exist (`sha256_sorted_json`, `sha256_jcs`, `sha256_text`) with doctests pinning example outputs; (b) migrate call sites **only** where the existing helper's bytes are provably identical (same `json.dumps` kwargs); (c) leave JCS-bound and persisted-identity sites alone unless a frozen-vector test proves byte equality. ADR-040 (Accepted) governs canonical JSON for integrity; the consolidation must cite it rather than invent a fourth form.
- **Risk:** medium if done carelessly (evidence reproducibility); low if gated by byte-equality tests.
- **Expected gain:** 43 definitions → ~3; one place to audit for ADR-040 compliance.
- **Validation:** `python -m unittest discover -s reference/tests -t reference`; `python reference/validate_canonical_json_v2_vectors.py`; `python scripts/check_runtime_baseline_equivalence.py` (the protected runtime surface must remain byte-equal or be declared per `docs/67-runtime-baseline-succession.md`). Any touched file under the Runtime Baseline boundary turns this from hygiene into a declared baseline transition.
- **Overlap:** ADR-040 / canonical-json-v2 workflows; #602 Rust canonical-bytes parity. Coordinate, do not duplicate.
