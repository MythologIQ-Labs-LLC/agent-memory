# Project Concept

## Why (One Sentence)

Agent Memory's defining product goal is governed, hierarchical, heterogeneous memory for agents: canonical structured records, lexical/semantic RAG and vector retrieval, graph relationships and GraphRAG-style context, episodic/temporal/procedural experience, and portable Markdown/filesystem representations working together under explicit provenance, isolation, and PAMA-controlled authority.

## Vibe (Three Keywords)

1. **Governed** - every durable mutation passes through Proportional Adaptive Mutation Authority; adaptation is never authority.
2. **Evidenced** - claims are repository-validated at declared boundaries; workflows, fixtures, and ADRs carry the proof, not prose.
3. **Portable** - memory substrates and cognitive providers are substitutable behind Capability Contract v3; no universal physical backend is doctrine.

## Anti-Goals (What This Is NOT)

- Not a single universal physical memory backend. Substrates and providers are qualified and substituted, not mandated.
- Not the owner of Qortara Agent Governance, AgentTrust, QOR Agent, or provider-specific semantics. Those consume Agent Memory/PAMA semantics; they do not redefine them here.
- Not required to implement every cognitive algorithm internally when a qualified pluggable implementation preserves the contract.
- Not a claim that passing repository validation proves a production memory system behaves correctly. Maturity boundaries stay explicit.
- Not a retrieval library. Memory is retained state that alters future interpretation, reasoning, and action across a persistence boundary.

## Forward Objective

Implement and qualify the complete hierarchical multi-representation architecture, not merely individual memory algorithms or a benchmark-driven collection of adapters. The original architecture and its qualification program are recorded in [#636](https://github.com/MythologIQ-Labs-LLC/agent-memory/issues/636) and the product North Star in [#668](https://github.com/MythologIQ-Labs-LLC/agent-memory/issues/668). Current evidence is bounded: [the substrate inventory](43-substrate-inventory-and-maturity.md) qualifies the single-host SQLite profile, not production PostgreSQL, Markdown, GraphRAG or distributed equivalents. Current execution state is tracked in [`BACKLOG.md`](BACKLOG.md), [`SYSTEM_STATE.md`](SYSTEM_STATE.md), and live GitHub issues. Historical Qor plans and ledger entries remain evidence, not the live queue.
