What the latest runs actually show

Accepted same-harness scores, experimental improvements and rejected regressions are different evidence classes. This checkpoint links to each source; no candidate run silently updates the accepted leaderboard.

Accepted AMB retrieval baseline (v6): Agent Memory 15/77 strict-success cases (mean precision 18.06%, mean recall 95.35%); Mem0 OSS 10/77 and BM25 8/77 on the same frozen retrieval-only protocol. The historical leaderboard below remains bound to its accepted snapshot. Accepted dashboard source ↗

October 20 selective-context experiment: 15/77 → 22/77. An opt-in lexical_content consumer package improved known-case AMB strict success by seven cases, with mean precision 18.06% → 32.43% and mean recall unchanged at 95.35%. This is a candidate diagnostic, not an accepted AMB lane: the full locked AMB CLI was not run and the 77 cases were already known. Raw paired evidence and limitations ↗

Why this mutation was not promoted: on the full external LongMemEval-S check, session complete recall@50 fell 419/419 → 418/419 and turn complete recall@50 fell 360/419 → 358/419. It lost required annotated evidence, and no-answer cases still received unrelated context. CHANGES REQUIRED, not a new default. Full 500-question-per-plane evaluation ↗

October 21 repaired v7 candidate: the cumulative runtime PR #836 reproduces accepted v6 results on all 77/77 AMB cases for Agent Memory, Mem0 and BM25, and all 500/500 questions per plane for Agent Memory and lexical LongMemEval baselines. Seven of nine planned comparator rows were imported and re-verified at its recorded checkpoint; Mem0 LongMemEval session and turn rows were pending. This is exact-result parity, not an AMB increase or an accepted v7 baseline. Revision-bound v7 comparison ↗

03 / The measurement gap

Where the evidence reaches.

A measurable peer is not the same as an untested competitor. This matrix is calculated from accepted source-pinned observations only, without borrowing vendor-published scores.

Benchmark families in the research and qualification queue

The accepted leaderboard is intentionally narrower than the benchmark programs under investigation. These links show separately owned methods; no run in one family earns a score in another.

AMB PrecisionMemBench: full 77-case retrieval-only same-harness comparison; accepted v6 and provisional v7 candidate evidence. Frozen lane qualification ↗

LongMemEval S and M: S provides separate session and turn retrieval planes and same-harness peers; M has accepted longitudinal Agent Memory evidence, but not an equivalent accepted multi-product cohort. Canonical profile interpretation ↗

AgentMemBench / MESA: source-retrieval, temporal currentness and mutation/semantic evidence; not interchangeable with answer-generation or AMB strict-success results. Formal MESA baseline ↗

SWE-ContextBench Lite: controlled software-agent context retrieval; preserve independent harness and model configurations before comparing products. Comparison protocol ↗

LoCoMo and next-generation task evaluations: external QA, lifecycle and cross-session task utility remain pending independently reproduced, profile-equivalent cohorts. LoCoMo comparator investigation ↗ · MemoryArena and external programs ↗
