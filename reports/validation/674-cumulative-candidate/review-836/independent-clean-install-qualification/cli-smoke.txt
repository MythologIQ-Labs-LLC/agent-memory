usage: agent-memory [-h] {config,discover,doctor} ...

Validate, discover, and diagnose the Agent Memory reference runtime.

positional arguments:
  {config,discover,doctor}
    config              runtime configuration operations
    discover            observe explicitly declared existing-stack signals
                        without mutating configuration
    doctor              diagnose configuration and bounded durable-state
                        recovery

--- gauntlet list
Gauntlet profiles: 4
- durability-recovery-alpha-v1 [gauntlet_native_gap]
  Claim-driven durability/recovery alpha for public reopen recovery, durable correction/deletion, deterministic recovered observation, scope isolation, and truthful checkpoint capability posture. Behavioral outcome and evidence sufficiency are reported separately.
- gauntlet-orchestration-retrieval-probe-v1 [baseline_or_probe]
  Deterministic three-record retrieval probe used to qualify Gauntlet orchestration, adapter transport, evidence normalization, and failure attribution. It is not an external efficacy benchmark.
- golden-keyed-retrieval-v1 [baseline_or_probe]
  Benchmark-author golden path: a deliberately small keyed-retrieval benchmark bound to a committed benchmark integration descriptor and a frozen input file. It demonstrates exact input identity, native-result retention, descriptor-driven normalization, and evaluator-integrity controls. It is not an external efficacy benchmark.
- governance-isolation-deletion-alpha-v1 [gauntlet_native_gap]
