## 2. Architecture

The `mesa-formal-v3` precedent is a frozen fixture, an executable runner bound by sha256, a test suite and a provenance-bearing report. These packages follow the same pattern.

| Component | Path |
|---|---|
| Frozen fixtures and DSL spec | `reference/fixtures/644-v7-replays/<replay_id>.json`, `README.md` |
| Runner, deterministic | `reference/run_644_v7_replays.py` |
| Independent verifier | `scripts/verify_644_v7_replays.py` |
| Tests | `reference/tests/test_644_v7_replays.py`, `reference/tests/test_644_no_eligible_value_disposition.py` |
| Evidence | `reports/validation/644-v7-replays/<replay_id>/{report,manifest}.json` |

**Independence of expectations.** Each fixture names its contract sources: docs 76, 77, 78, 79 and 81, and META_LEDGER Entry #125. It records their sha256 at `c4827f9`. Every expectation was written from those documents. The fixtures use new vocabulary (Vireo, Pellucid, Corvid, Halyard, Tamarack); a test asserts that no holdout entity appears.

**Contract-defined names only.** Where the contracts name an outcome (`coverage_observed_unattested`, `value_coherence_unresolved`, `recall_observation_unverified`, `no_eligible_value`, and the obstacle counters), the fixtures assert it exactly. Where they don't, the fixtures assert observables: counters, missing needs, "not clean", and "no stop".

**Runner surface.** The runner drives the public `AgentMemory` facade, `ControlledRecallPlanner` and the documented #644 observer and adapter methods. Private internals are touched only for declared fault injection (S9) and the independent census oracle (A9).

**Provenance.** Each report records the source commit, the runtime tree (`HEAD:reference/agentmem_ref`), any dirty paths, and the fixture and runner sha256. It also records the Python, SQLite and platform versions and an observations digest. A dirty source tree, other than the evidence directory, can never yield PASS.

### What each replay tests

**1. Typed sufficiency noninterference and negative controls.**
- N1: twin stores, run with and without every observer, give identical facade outputs, canonical facts, audit events and state digest.
- N2: a single observation is read-only.
- N3: meeting the count target with untyped facts is not typed sufficiency.
- N4 and N5: controller-estimate labels, and forged `runtime_typed_observation` labels, never confer coverage or a stop.
- N6: forged report authority is refused.
- N7: malformed needs fail closed. This covers empty, duplicate, non-canonical spelling and untyped keys.
- N8: the report does not depend on need order.
- N9: capped routes are reported as budget-bound and unexecuted routes as unexecuted.
- N10: coverage outside the admitted set is refused.

**2. Persisted typed-slot sufficiency and admission recheck.**
- A1 and A2: only caller-declared, unflagged, exact-slot facts support a need. Extracted, hedged, negated and attributed claims instead count as 4 qualified obstacles.
- A3: admission is rechecked after forget, dispute or supersede.
- A4: injected foreign or nonexistent references add nothing and leak no value.
- A5: a reader in another project sees nothing.
- A6: hidden or budget-capped admissible competitors are counted. Facts that are invisible, forgotten, disputed or in another project are never counted.
- A7: temporal bounds behave as documented. A future `valid_until`, an expired one, and a prospective `valid_from` are obstacles; a past `valid_from` is clear.
- A8: missing evidence is reported as missing.
- A9: the census equals an independent full-store enumeration through correction, forget and restart.
- A10: reports are identical after restart.
- A11: multiplicity counts distinct facts.

**3. Admitted typed-value coherence.** These cases encode doc 77's disposition table row by row: `no_eligible_value`, `same_value_observed`, `competing_values_unresolved`, `coexistence_possible`, `cardinality_unresolved` and `change_assertion_unresolved`.
- V7: comparison is strict literal equality, so case variants compete.
- V8: an unresolved disposition takes precedence and yields continuation.
- V9: disputed and forgotten facts are excluded.
- V10: no raw values appear in the report.
- V11: the result is independent of write order.
- V12: a stop cannot be constructed over unresolved values.
- V13: multiplicity counts facts, not sources. This is recorded as a boundary.

**4. Committed transition witness.**
- T1: an asserted change alone yields no witness.
- T2: an explicit governed application yields exactly one `applied_state_change_observed` witness, naming the source, the prior, the current head and the original proposal.
- T3: a witness never claims the immediate successor, quality, stop or authority.
- T4: both the source and the current head are required.
- T5: a reader in another project sees nothing.
- T6: an uncited correction, or one citing a forged proposal, yields nothing.
- T7: a cited error correction yields `applied_error_correction_observed`.
- T8: duplicates are refused.
- T9: the witness survives restart.
- T10: a later governed change still yields a witness for the latest head.
- T11: a forgotten source yields nothing.
- T12: the witness discloses no raw text, and observing it writes nothing.

**5. Same-slot counter-evidence and immutable stop gate.**
- S1: no stop is ever proposed, even with fully agreeing coverage.
- S2: eight classes of same-slot counter-evidence each block clean coverage.
- S3: the receipt is captured, immutable and claims nothing.
- S4: each of ten post-capture mutations is detected and never reads as clean.
- S5: a missing receipt never reads as clean.
- S6: a re-minted receipt verifies, which demonstrates it is not authentication, and still no stop follows.
- S7: forged receipt claims are refused.
- S8: refused identities are not disclosed.
- S9: missing or corrupted enumeration raises.
- S10: a controller claiming authority is refused.
- S11: hostile inputs make verification return false, never raise.
- S12: F6 is recorded. The untyped competitor still reads `coverage_observed_unattested`, and no stop is proposed.

## 9. Authority boundaries preserved

Each boundary below is enforced by at least one case:
- **Receipt hashes are not provenance.** S6 shows a caller can re-mint a matching receipt. The tamper challenge shows static verification can't catch a consistent forgery.
- **A matching receipt is not a slot-closure proof.** S3 and S7: `slot_closure_attested` is always false. The census (A6, A9) is a separate read-time check.
- **Controller confidence confers nothing.** N4: estimates never cover a need. S10: a plan claiming authority is refused.
- **Missing or corrupted observations fail closed.** S5, S9 and S11.
- **F6 is unresolved.** S12 records `coverage_observed_unattested` for an untyped competitor. Only the absence of a stop is required, and nothing asserts F6 is fixed.
- **Positive stopping stays disabled.** S1, N5 and V12, and every `NO_STOP` expectation across all five replays.
