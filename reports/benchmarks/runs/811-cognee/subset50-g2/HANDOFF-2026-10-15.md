## Why the run is handed off

every corpus item, one item at a time.

On a 4 vCPU host, with no GPU and shared with the Hindsight, MemPalace and Mem0 runs:
- Each corpus item takes about 1.5 minutes.
- Each session-plane question has about 50 items, so it takes 60–75 minutes.
- The first 2 session questions finished at 14:01Z and 15:09Z, both scored with 0 runtime
  errors.

At that rate:
- The 50 session questions need about 60 hours.
- The turn plane ingests about 10 times more items per question, so it needs several more
  days.

That does not fit in this execution session. The preregistration is unchanged and stays in force.
No subset, plane, `top_k` or other setting is narrowed to make the run fit, and no stopping rule
is added after seeing outcomes.

## How to resume

The driver is resumable per question and appends to
`<out>/<plane>.cognee_gliner_local.rows.jsonl`. Resume on a host with more CPU, or with a GPU for
GLiNER, as follows:

1. Check out the commit that holds this file. The adapter is
   `reference/longmemeval_cognee_bridge.py` 0.1.1-candidate.
2. Recreate the environment byte-identically from `../cognee-venv-freeze.txt`.
   `uv pip install --no-sources -c ../cognee-venv-freeze.txt "cognee[gliner,fastembed]==1.6.4"`
   followed by `pip freeze` must equal the freeze.
3. Place the GLiNER and fastembed model files at the revisions in `model-pins.txt`. Verify every
   sha256 before starting.
4. Copy this directory's partial `session.cognee_gliner_local.rows.jsonl` and
   `preregistration.json` into a fresh `<out>`. The driver rejects a mismatched preregistration.
5. Run as an unprivileged user with no credentials. The bridge refuses to start if it sees any
   LLM or cloud key. Use exactly this environment and command:

```bash
env -i PATH=/usr/bin:/bin PYTHONHASHSEED=0 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
  HF_HOME=<hf-home with the pinned GLiNER snapshot> FASTEMBED_CACHE_PATH=<pinned fastembed cache> \
  COGNEE_BENCH_ROOT=<disposable dir> HOME=<user home> \
  <cognee-venv>/bin/python reference/run_longmemeval_resumable.py \
    --input longmemeval_s_cleaned.json \
    --expected-sha256 d6f21ea9d60a0d56f34a05b609c79c88a451d2ae03597821ea3d5a9678c3a442 \
    --subset-size 50 --granularity session --granularity turn \
    --backend cognee_gliner_local \
    --external-backend longmemeval_cognee_bridge:install_longmemeval_cognee_backend \
    --out <out>
```

Wrap the command with `scripts/record_comparator_execution.py` to get `exec.json`, stdout and
stderr. When both planes reach 50 rows, run the same command with `--finalize`, then re-hash the
model files against `model-pins.txt`.
